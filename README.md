# reproducibility_template
Template to use for reproducibility projects in PSYCH 201B

This repository simulates De la Fuente et al. (2021, Journal of Animal Ecology)'s study on common marmoset behavioral performance when controlling food distribution and productivity.
The simulation focus on the age effect, looking at how juveniles and adults differ (H1b).

Folders:
  original_paper: original paper and dataset used for simulation
  
  writeup: codes for report
  
  simulation: codes for simulation
